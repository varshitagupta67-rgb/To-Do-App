# To-Do-App

A simple and interactive To-Do List application built using HTML, CSS, and JavaScript.

## Features

- Add new tasks
- Edit existing tasks
- Delete tasks
- Clear all tasks
- Display the number of pending tasks

## Technologies Used

- HTML
- CSS
- JavaScript

## What I Learned

- DOM manipulation
- Event handling
- JavaScript functions
- Updating webpage content dynamically
- Managing user interactions
